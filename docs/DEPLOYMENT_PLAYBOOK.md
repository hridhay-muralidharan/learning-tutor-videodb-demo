# Pathway learning — deployment playbook

This is the proposed reusable deployment sequence. It is a product hypothesis to be tested, not a claim that the full model has already been deployed.

## Seed: urban early adopters

Recruit families already willing to experiment. Start with a bounded pathway module. Establish baseline learning, aspiration clarity, family support, time, devices, and existing outcomes. Measure both benefit and the privilege required to participate.

## First roots: gram panchayats

Work with local teachers, families, community institutions, and administrators. Adapt language, examples, schedules, offline access, mentorship, and evidence collection. Do not treat the gram panchayat as a smaller urban pilot.

## District playbook

Document staffing, teacher development, content governance, local partners, data protection, funding, monitoring, escalation, and cost. Identify what can be reused and what must be locally configured.

## State playbook

Align with state curriculum and examination pathways. Establish procurement, teacher capacity, language support, public financing, outcome reporting, and interoperability. Build the case using evidence from multiple districts, not one exceptional site.

## National public infrastructure

Package standards, APIs, source and assessment specifications, safety benchmarks, deployment checklists, and reusable building blocks. The end state is a community and public-good ecosystem, not a single platform that owns the education journey.

## Capital and diffusion loop

`early outcomes → trust and advocacy → grants, donations, partners → lower-cost deployment → broader evidence`

Funders should see outcome evidence, leading-indicator validity, cost per learner, additionality, learner wellbeing, and a transparent path to underserved communities.
