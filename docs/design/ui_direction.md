# UI Direction

## Product Tone

The learner app should feel like a calm academic workbench. It should be clear, serious, and low-friction. It should not feel like a marketing page, a generic AI chatbot, or an analytics dashboard.

## Visual Hierarchy

Order of importance:

1. Current learning task.
2. Primary next action.
3. Why this action is recommended.
4. Practice and confidence state.
5. Source/evidence state.
6. Secondary course map and metadata.

## Layout Principles

- Start screen uses one dominant task card.
- Lesson screen uses a focused reading/practice workspace.
- Practice screen uses one question or small set at a time.
- Review screen is an actionable list, not a punishment board.
- Sources screen is an inspection surface, not the default learning surface.

## Clutter Rules

- One primary CTA per screen.
- No nested cards.
- No decorative panels that do not represent real objects.
- No three-column dashboard on first open.
- No source dump in the Start screen.
- No raw artifact filenames as primary learner copy.
- No sticky control that covers content.

## Color And Typography

- Use restrained academic colors.
- Use color for state and attention, not decoration.
- Body text must remain readable on mobile.
- Headings should fit their containers without clipping.
- Buttons must have stable dimensions and no text overflow.

## Interaction States

Every major screen needs:

- empty state
- demo-placeholder state
- source-backed state
- missing-source state
- completed/practiced/review-needed/mastered state where relevant

## Mobile Direction

- Mobile is learner-first.
- Institution and developer heavy workflows are desktop-first future surfaces.
- Learner mobile uses stacked sections and top or bottom navigation with no horizontal scroll.
- Sources open as a separate screen or collapsible section, not as a permanent side panel.
- Touch targets should be at least 44px high.

## Accessibility Direction

- Keyboard navigation must work for core learner flow.
- Focus states must be visible.
- Progress and correctness cannot be color-only.
- Form controls need visible labels.
- Reduced-motion preference must be respected.

## Inspiration To Borrow

- Coursera: clear next action and progress.
- Udemy: focused course player with notes/resources/transcripts as tools.
- Khan Academy: mastery and practice state.
- Moodle: required activity awareness for institutional contexts.
- UDL: flexible access, support, and expression.

## Inspiration To Avoid

- Chatbot-first interface.
- Busy analytics dashboard for learners.
- Game-like visual noise.
- Hidden source grounding.
- Product identity tied to one demo subject.
