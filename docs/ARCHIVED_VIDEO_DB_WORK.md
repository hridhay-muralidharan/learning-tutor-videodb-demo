# Archived prior work: VideoDB chemistry study app

This directory contains an earlier implementation of a source-grounded GATE Organic Chemistry study workbench. It used approved syllabus, textbook, lecture, and question-bank material, with VideoDB retrieval, concept mapping, practice, confidence, and review.

The implementation is preserved because it is real prior work and may contain reusable engineering lessons. It is not the product described by the current pathway-learning thesis. The current product documentation does not claim that video search or chemistry tutoring is the right first mechanism.

## Why it is archived

The pathway thesis begins with aspiration, contribution, self-discovery, hard gates, alternatives, and generational diffusion. The chemistry application begins with an already-selected exam subject and a study loop. Treating the latter as the first expression of the former created a force-fit.

## What remains useful

The code may later contribute implementation patterns for source provenance, grounded content, assessment, and institutional controls. Those patterns should be reused only if the chosen prototype genuinely needs them.

## Current status

No replacement prototype has been selected yet. The next prototype will be chosen from the product question, first user, deployment context, and evidence requirement—not from the capabilities of this archived codebase.
